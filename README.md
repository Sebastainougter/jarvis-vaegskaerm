# Vægskærm

Statisk side til en altid-tændt skærm. Viser et animeret hologram, ur, vejr for Køge og beskeder fra et Google Sheet, der læses via Googles offentlige gviz-feed.

Siden indeholder ingen hemmeligheder, kun ID'et på et sheet, som er delt som "alle med linket kan se". Åbn `index.html` og tryk én gang for at aktivere lyd.
